
# 🍔 FoodCatalogue

A simple and intuitive food catalogue iOS application built using **SwiftUI**. Organize food categories, manage products, and keep track of product prices in one place.

## ✨ Features

- **Category Management** – Create, view, and edit food categories.
- **Product Management** – Add, view, and edit products within categories.
- **Product Pricing** – Store and manage product costs.
- **Navigation** – Navigate between categories and their products.
- **Reusable UI Components** – Shared components for adding and editing data.

## 🛠️ Tech Stack

- **Language:** Swift
- **Framework:** SwiftUI
- **Architecture:** MVVM
- **IDE:** Xcode
- **Dependency Management:** Swift Package Manager

## 🚀 Getting Started

### Prerequisites

- macOS
- Xcode
- Basic knowledge of Swift and SwiftUI

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/gRajesh-3/FoodCatelogue.git
   ```

2. Navigate to the project directory:

   ```bash
   cd FoodCatelogue
   ```

3. Open the Xcode project:

   ```bash
   open FoodCatelogue.xcodeproj
   ```

4. Resolve Swift Package Manager dependencies if required.

5. Select an iOS simulator and click **Run (⌘ + R)**.
